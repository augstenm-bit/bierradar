# Bierradar

Findet Bier-Aktionen aus den Flugblättern im Bezirk Amstetten und meldet,
wenn deine Lieblingsbiere günstig zu haben sind.

- `bier_app/` – die App (Flutter, iPhone und Android)
- `server/abruf.py` – holt die aktuellen Bier-Angebote (läuft stündlich über GitHub Actions)
- `server/angebote.json` – die aktuellen Angebote, die die App lädt
